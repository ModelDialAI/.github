**ModelDial 是我们一起做的 AI 模型评测项目。** 我们通过具体任务比较模型的能力、表现与费用，也把模型解题的过程做成可以观看、回放和讨论的挑战。

## 从评测到挑战

**[ModelDial 主站](https://modeldial.com)**<br>
在自建私有评测集上比较模型与思考档位，查看榜单、评分方法和费用，帮助你选择适合任务的模型。

**ModelDial 模型挑战赛**<br>
让多个模型面对同一道题，把观察、推理与工具操作呈现在同一个舞台上。既用于评测，也用于视频与直播展示。

| 挑战题目 | 当前进展 |
| :--- | :--- |
| 魔方 · 二阶 / 三阶 | 已支持多模型评测、轨迹回放与题目排行榜 |
| 推箱子 | 规划中 |
| 更多题目 | 围绕可验证结果、可回放过程持续打磨 |

## 我们如何做比较

- **同题对照**：支持固定随机种子，在统一题面和预算下比较模型。
- **过程留痕**：保存题目、配置参数、工具调用与结果，回看模型在哪一步成功或卡住。
- **评分有依据**：各题目独立计分；魔方按阶数与难度加权，同题重复评测取平均，关注稳定性。
- **区分能力与故障**：只有整轮参赛模型均正常结束的数据进入统计；网络中断不当作模型解题失败。

## 开源计划

挑战赛目前仍在内部迭代。**等题库与评测流程打磨成熟，我们计划在这个组织逐步开源挑战赛题库。**

我们会先把题目规则、生成方式、评分口径和复现说明整理清楚，再发布可供大家使用和讨论的版本。具体开放范围与许可证以正式发布说明为准。

挑战赛题库的开放计划与主站的私有评测集分别推进。
